# 🎓 Unipulse – Engineering Admission Assistance Platform

## 📌 About the Project

**Unipulse** is a web-based platform designed to help engineering students overcome challenges during the admission process, particularly for **MHT CET** and **Direct Second Year (DSY)** admissions.

The platform aims to simplify the engineering admission journey by providing students with useful information, resources, and assistance in one place.

Our goal is to make the admission process easier, more accessible, and less confusing for aspiring engineering students.

## 🎯 Problem Statement

Every year, thousands of students face difficulties during engineering admissions through MHT CET and DSY.

Some common challenges include:

- Difficulty understanding the admission process.
- Confusion regarding admission procedures and requirements.
- Difficulty finding relevant admission-related information.
- Lack of proper guidance during important admission stages.
- Challenges in understanding college and admission options.

**Unipulse aims to address these challenges through a centralized and student-friendly platform.**

## ✨ Key Features

- Student-friendly web interface.
- Admission-related information and assistance.
- Support for MHT CET aspirants.
- Support for Direct Second Year (DSY) engineering aspirants.
- Organized access to relevant student resources.

## ⚙️ Installation and Setup

### Prerequisites

Make sure you have installed:

- Node.js
- MongoDB
- Git
- VS Code (recommended)

### Step 1: Clone the Repository

```bash
git clone https://github.com/gajanan-2004/Unipulse.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Unipulse
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Configure Environment Variables

Create a `.env` file and add your MongoDB connection string and required configuration.

Example:

```env
MONGO_URI=your_mongodb_connection_string
PORT=3000
```

Never upload real database credentials or passwords to GitHub.

### Step 5: Start the Application

```bash
npm start
```

If your project uses a different start command, replace this with the correct command from your `package.json`.
